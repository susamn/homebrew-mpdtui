# homebrew-mpdtui

Homebrew tap for [mpdtui](https://github.com/susamn/mpdtui), a
lazygit-style terminal UI for MPD (Music Player Daemon).

## Install

```bash
brew install susamn/mpdtui/mpdtui
```

Or tap first, then install:

```bash
brew tap susamn/mpdtui
brew install mpdtui
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
